# Diffuse — 互動緞帶花

以 Three.js 製作的程序化立體花朵。開合參考使用者提供的 Steelworks「Unfold, Form, Flourish」影片；新版造型與材質參考使用者提供的藍白花朵正面／側面／背面圖片。模型由 64 片有厚度的緞帶花瓣、四層弧形花冠、12 片尖形花萼、花托、漸細花莖與三片捲葉組成。花莖會隨花朵朝向重新銜接花托，捲葉接在花莖的實際曲線上。

花瓣兩面均有深藍至霧白的漸層，搭配程序化細纖維、緞面反光、各向異性高光、方向光陰影及近似的背光散射。這是可即時變形的原創程序化模型，並非參考圖片或影片的原始模型。

## 啟動

在此資料夾執行 `npm install`，再執行 `npm run dev`，開啟終端顯示的本機網址。正式版本使用 `npm run build` 產生 `dist`。

## 分享與發布

網站透過 GitHub Pages 發布。推送到 `main` 會執行測試、建置並自動更新網站；也可手動執行 GitHub Actions 的 `Deploy Diffuse Garden`。Vite 使用相對資源路徑，支援 GitHub Pages 的專案子路徑。

每次開啟網站預設三朵花收合，「保持盛開」不勾選；滑鼠靠近後才展開。檢視模式和調整參數只作用於本次開啟，不會更改其他訪客的初始狀態。

## 操作

- 三朵花獨立感應：滑鼠移入花苞範圍時展開，離開後自動收合。
- 盛開時移動滑鼠會牽引附近花瓣，離開後以彈簧回彈；按住花朵拖曳也能牽引。
- 拖曳空白處旋轉視角；滾輪縮放。觸控裝置按住花朵展開、移動牽引，放開收合。
- 「最大展開」設定滑鼠移入後的盛開幅度，花朵平時保持收合。
- 「編輯花朵」選擇個別實例，或直接點選畫面中的花朵；左右朝向、俯仰傾斜、花盤旋轉與凌亂程度均獨立保存於當前場景。
- 「凌亂程度」調整花瓣長短、角度、扭轉、捲曲及捲葉變化；「換一種花瓣排列」切換固定亂數種子，同一組排列不會每幀跳動。
- 「正面」「側面」「背面」直接轉動選定花朵；「正面・側面・背面展示」同時比較三個角度，並保持盛開。
- 取消「保持盛開」後恢復滑鼠移入展開、移出收合。「全體自然朝向」替每朵花安排不同角度。
- 可新增或移除花朵，最多 9 朵，自動重新編排位置。重新整理頁面會回到預設三朵。
- 控制面板可調環境光、環境反射、曝光、背景色、主光強度／顏色／方向／高度、補光及輪廓光。
- 花瓣材質提供粗糙度、金屬感、表面亮膜、緞面光澤、絲緞反光方向感、纖維紋理及背光柔透感；動態提供開合速度與牽引力度。
- 三組配色、微風擺動開關、視角重設、獨立燈光材質重設及 PNG 匯出。
- 支援行動裝置與減少動態效果偏好。收合且靜止的花瓣會略過重複模型計算。

## 驗證

執行 `npm test` 驗證分層展開、不同幀率回彈、穩定亂數、各角度的花莖接合、最大凌亂程度的實際幾何、花瓣正反面漸層及多實例資源管理。執行 `npm run build` 建置正式版。

模型位於 `src/flower-model.js`；曲線與亂數在 `src/botanical-math.js`；材質在 `src/flower-materials.js`；場景與控制器在 `src/app.js`。新增花朵共用材質與紋理，每個實例保留自己的形狀、角度與動畫狀態。

需要支援 WebGL 的現代瀏覽器。字型使用 Google Fonts，無網路時使用系統備用字型。Three.js 隨建置打包。
